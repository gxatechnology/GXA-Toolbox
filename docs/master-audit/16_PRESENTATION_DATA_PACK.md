## Use guidance

- Replace no verified number with an aspirational one.
- Do not use “100% offline,” “all browsers,” “live exchange rates,” “digital signatures” or “faithful PPT conversion.”
- Label future features and monetization as roadmap, not current capability.
- Use screenshots only from the current product/build and retain route/date captions.
