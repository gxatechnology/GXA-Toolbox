# Tool functionality matrix — Phase 4A / Phase 4C IN PROGRESS

## Phase 4C update — 2026-10-11

The 95-row Phase 4A baseline below remains historical evidence, not new certification. The current per-tool advanced backlog is in `ADVANCED_TOOL_FEATURE_MATRIX.md` (95 rows). No publication flag has changed: 81 indexable/ads-eligible, 14 noindex/ad-free.

Edit PDF now has a **partially advanced, bounded increment**: page move/rotate/duplicate/delete/blank insertion; lazy small thumbnails; 12 standard font variants; text underline/line spacing; opacity; ellipse/line/arrow/highlight/underline/strike marks; fill/stroke width; overlay order and duplication; page-aware undo/redo. New tests independently reopen exports and check original content, rotations, CropBox, actual drawing operators, form values and field-tree/widget preservation. Unsafe deletion/duplication of annotated/form pages is rejected; rotate before adding overlays. New mobile/desktop and keyboard browser checks supplement, not replace, the existing form/signature/reset suite.

Inserted image crop/quarter-turn rotation/replacement/restore are also implemented in Edit PDF; preview/export pixel comparisons include transparency and undo. Merge PDF now has per-file page selections, repetitions/omissions, relative rotations and reopened output verification, with File-bound settings surviving queue reordering. Unsupported live forms are explicitly rejected instead of silently losing field behavior.

Split PDF adds validated output groups (including non-contiguous/repeated selections), a file-by-file plan, source-page inspection, bounded ZIP creation and reopen validation. Organize PDF adds selected-source relative rotation and strict blank-page validation, prevents repeated-page watermark duplication, preserves pages beyond the 60-thumbnail cap, and provides keyboard ordering. Both reject unsupported live forms and allow Adjust settings without re-uploading; Start Over clears the complete working state. Actual parsed outputs and command/browser results are recorded in `ADVANCED_TOOLS_PHASE4C.md`.

These four tools remain **PARTIALLY ADVANCED**, not fully advanced: original static text rewriting, OCR-region reconstruction, secure redaction, new form creation, live-form page-copy preservation and other requested capabilities remain deferred. The other 91 tools have no new advanced-feature implementation in this increment. Do not label all tools FULLY WORKING from route-width checks.
