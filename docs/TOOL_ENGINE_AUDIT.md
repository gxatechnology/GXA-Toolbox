# GXA Toolbox 91-tool browser-engine audit

## Scope and method

The canonical source for this matrix is `toolsList` plus `extraTools` in `public_html/assets/app.js`. The registry contains **91 unique tools**: 22 PDF, 4 image, 27 utility, 2 ZIP, 21 convert, and 15 calculator tools. Every registry ID appears exactly once below.

The audit distinguishes the implementation that existed at the start of this pass from the selected engine disposition. A final classification describes the honest supported scope, not a promise of native Microsoft Office fidelity. “Local” means that file bytes stay in the browser; a future Netlify fallback would require an explicit upload and a separate privacy disclosure. Memory estimates are working-set bands: Low (generally under 50 MB), Moderate (roughly 50–200 MB), and High (can exceed 200 MB with large inputs or model data).

The only accepted final classifications are:

- **FULLY WORKING — BROWSER**: native JavaScript or browser APIs provide the advertised output.
- **FULLY WORKING — WASM**: the primary engine is WebAssembly, normally isolated from the UI thread.
- **FULLY WORKING — NETLIFY FUNCTION**: the primary engine is an explicitly disclosed Netlify upload workflow.
- **WORKING WITH BROWSER LIMITATION**: the browser workflow is useful and honest, but fidelity, capability, or practical file-size limits are material.
- **NOT CURRENTLY FEASIBLE**: no production-safe browser implementation can honestly provide the advertised result in this deployment.

### Shipped engine payload

The newly vendored, route-lazy engine code totals **3,432,992 bytes (3.27 MiB)** before HTTP compression. It is not added to the initial homepage JavaScript payload: qpdf JS/WASM is 1.31 MiB, SheetJS is 0.91 MiB, Mammoth is 0.61 MiB, PptxGenJS is 0.26 MiB, the Tesseract wrapper/worker is 0.17 MiB, and the GIF/qpdf route workers and codecs are about 21 KiB. OCR additionally downloads the selected Tesseract core and English trained-data package from the official jsDelivr package endpoints on first use. The PDF file itself is never sent to that endpoint.

Direct npm dependencies added for reproducible fixtures/contracts are `@neslinesli93/qpdf-wasm`, `gifenc`, `mammoth`, and `tesseract.js`. PptxGenJS and SheetJS are shipped as licensed browser bundles only; the unnecessary Node PptxGenJS dependency was removed after its transitive audit finding. `npm audit --omit=dev` reports zero known production vulnerabilities after that removal.

## High-priority blocker decisions

The baseline blocker set contains exactly 13 IDs: `protect-pdf`, `unlock-pdf`, `word-to-pdf`, `excel-to-pdf`, `ppt-to-pdf`, `pdf-to-ppt`, `pdf-to-excel`, `epub-to-pdf`, `pdf-to-epub`, `gif-maker`, `gif-to-png`, `extract-images-pdf`, and `ocr-pdf`.

- Protect/unlock use genuine qpdf encryption/decryption in a worker; they never claim password recovery.
- DOCX and spreadsheet conversions provide semantic/data fidelity with visible limitations, not Microsoft Office print fidelity.
- PDF-to-PPT creates valid page-image slides and explicitly does not claim editable reconstruction.
- EPUB conversions target reflowable content and standards-valid packaging; complex CSS and fixed-layout books remain limited.
- GIF encode/decode use real frame codecs and produce validated GIF or PNG-in-ZIP output.
- Embedded PDF image extraction is distinct from page rendering and reports unsupported object types honestly.
- OCR is sequential, cancelable, worker-based, and produces extracted text; it does not claim an invisible searchable PDF layer.
- PPT/PPTX-to-PDF remains unavailable because a reliable presentation renderer is not practical in this static browser/Netlify deployment. No placeholder PDF is emitted.

## Verification rule

Engine selection alone does not prove a tool’s output. Converter evidence must include valid input, executed processing, result/download generation, signature or package validation, and reopening with an independent parser/viewer. The final release report should derive its counts from those recorded results and must narrow a row’s classification if that evidence does not pass.
