## What changed

The 81 indexable tools now consume one reviewed metadata map from `scripts/tool-seo-intents.mjs`. Titles use the real tool name and a restrained online/category qualifier where useful. Descriptions come from the existing verified tool introduction or description and never end in a generated ellipsis. The generator applies the same title and description to HTML title, meta description, Open Graph, Twitter, and JSON-LD.

The initial HTML keeps the existing H1, introduction, how-to steps, feature explanations, examples, supported formats, privacy boundary, limitations, FAQs, and related links. Its generic H2 labels are now contextualized per tool:

- `How to Use` → `How to Use {Tool Name}`
- `About, Features and Practical Uses` → `About {Tool Name}`
- `Privacy, Formats and Limitations` → `{Tool Name} Formats, Privacy and Limitations`
- `Frequently Asked Questions` → `Frequently Asked Questions About {Tool Name}`
- `Related Tools and Guides` → `Related {Tool Name} Tools and Guides`

No tool engine, route, body copy, FAQ answer, processing claim, index decision, or canonical URL was changed.
